# Provenance

The canonical solution is `reproduce/materialized/reproduction/intact.glb`,
produced by importing the fixed KhronosGroup glTF Sample Assets Boom Box at
revision `c6a6bd13ab2b3c685c7903d03561b8a9392f38b8` in the approved
`visual-media` runtime. The public input is the corresponding
`reproduce/materialized/reproduction/stripped.glb`, generated by removing the
real mesh's UV layer and material slots while leaving positions, normals, and
indices untouched. The public PNG is the canonical render only as a visual
reference; the full GLB remains evaluator-only.

The source model files are CC0-1.0. The Draco representation was not used
because the pinned runtime does not provide its decoder; this candidate is
limited to the validated ordinary GLB path.
